📊 Customer Shopping Behavior Analysis

A data analytics project focused on understanding customer purchasing patterns, product preferences, customer segmentation, and subscription behavior using real-world transactional data.

🛠️ Tools & Technologies
🐍 Python – Data cleaning, preprocessing & exploratory analysis
🗄️ PostgreSQL – Database integration and data storage
🔍 SQL – Business-oriented data analysis
📊 Power BI – Interactive dashboard and data visualization
📓 Jupyter Notebook – Analysis and documentation
📌 Key Analysis
Analyzed 3,900 customer transactions
Cleaned and transformed customer shopping data
Handled missing review ratings
Performed customer segmentation into New, Returning, and Loyal customers
Analyzed revenue by gender and age group
Compared subscribers vs. non-subscribers
Analyzed discount usage and product ratings
Identified top-selling products across categories
Compared Standard vs. Express shipping behavior
Built an interactive Power BI Customer Behavior Dashboard
📈 Dashboard Highlights

The Power BI dashboard includes:

Total customers
Average purchase amount
Average review rating
Revenue by category
Sales by category
Revenue and sales by age group
Subscription status analysis
Interactive filters for customer and purchase attributes
💡 Key Outcome

This project demonstrates an end-to-end Data Analytics workflow, from raw data cleaning and SQL-based analysis to interactive business intelligence dashboards.

Python → PostgreSQL → SQL → Power BI → Business Insights
